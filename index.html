A hardware shop managing hundreds of products relied on manual, paper-based stock tracking.

What I built

As sole developer I designed the database schema, wrote all backend logic in PHP and MySQL, and built a responsive Bootstrap 5 front end with a secure admin dashboard.

The outcome

The shop now manages its catalogue, real-time stock, sales and customers digitally. The system is live on cPanel shared hosting.
