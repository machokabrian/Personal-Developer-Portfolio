# Personal Developer Portfolio

My personal portfolio website, showcasing my projects, skills and experience as a software developer.

**Live site:** https://personal-developer-1-portfolio.vercel.app/

![Screenshot](screenshot.png)

## Features
- Responsive, mobile-first design
- Sections for projects, skills and experience
- Contact form with email notification (PHP)
- Downloadable CV
- Continuous deployment: every push to `main` updates the live site

## Built with
- HTML5
- CSS3
- Vanilla JavaScript
- PHP (contact form)
- Deployed with continuous deployment

## Run it locally
1. Clone the repo: `git clone https://github.com/machokabrian/Personal-Developer-Portfolio.git`
2. Open `index.html` in your browser.
